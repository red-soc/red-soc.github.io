Reading the specification slowly saved me hours of guessing about reserved fields. A common mistake is trusting offsets from the file without checking that they stay inside the buffer. I tested the result on both a Linux machine with gcc and a Windows machine with MSVC.

## Background

Next I want to extend the tool so it can print a readable summary of every section. Symbol names are stored in a string table, and each entry points into it by index. Padding bytes between fields can differ between compilers, so packed structs need extra care. Writing the parser as a set of small functions made each structure easy to verify separately.

```makefile
all: app
app: main.o
	gcc -o app main.o -ldl
```

I wrote a small C program to dump the structure and compared the output with a hex editor. Unit tests with tiny hand-made binaries caught bugs that real programs hid.
