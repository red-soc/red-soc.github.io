## Background

Comparing two builds of the same source showed how much optimization flags change the layout. The linker places each section at an aligned address, and the loader maps them into memory later. I kept notes in a cheat sheet so I could check field sizes quickly later.

```c
for (int i = 0; i < nsections; i++) {
    printf("%-8s 0x%08x\n", sec[i].name, sec[i].addr);
}
```

Padding bytes between fields can differ between compilers, so packed structs need extra care. I wrote a small C program to dump the structure and compared the output with a hex editor.
