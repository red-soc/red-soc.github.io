The relocation table lists every place the loader must patch when the image is not mapped at its preferred base. Every field is little-endian on x86, which matters when you read raw bytes from a file.

## Background

The linker places each section at an aligned address, and the loader maps them into memory later. Unit tests with tiny hand-made binaries caught bugs that real programs hid.

```c
for (int i = 0; i < nsections; i++) {
    printf("%-8s 0x%08x\n", sec[i].name, sec[i].addr);
}
```

On Linux the dynamic loader resolves shared library functions lazily through the procedure linkage table. A common mistake is trusting offsets from the file without checking that they stay inside the buffer.
