## Background

On Linux the dynamic loader resolves shared library functions lazily through the procedure linkage table. Symbol names are stored in a string table, and each entry points into it by index.

```c
uint16_t magic = *(uint16_t *)buf;
if (magic != 0x5A4D) {
    fprintf(stderr, "not a PE file\n");
    return 1;
}
```

Reading the specification slowly saved me hours of guessing about reserved fields. Next I want to extend the tool so it can print a readable summary of every section. Writing the parser as a set of small functions made each structure easy to verify separately.
