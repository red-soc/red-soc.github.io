## Background

I kept notes in a cheat sheet so I could check field sizes quickly later. The header begins at a fixed offset, so the parser reads a few bytes and validates the magic value first.

```bash
readelf -S ./a.out | head -20
objdump -d ./a.out | less
```

A common mistake is trusting offsets from the file without checking that they stay inside the buffer. I tested the result on both a Linux machine with gcc and a Windows machine with MSVC. Reading the specification slowly saved me hours of guessing about reserved fields. Writing the parser as a set of small functions made each structure easy to verify separately.
